model_path_provider_type 🔒
Render one schema-driven field descriptor as a dialoguer prompt and collect the user’s answer. Returns None when the user cancels (Esc on a select / confirm), Some(value) otherwise. Used by both the model-provider field form and the channel field form so the two sub-flows share a single prompt implementation. Recognize a providers.models.<type>.<alias>.model config path and return <type> if the family is in the canonical model-provider registry. Used by config set to offer a live model picker when no value is supplied. Returns None for any other path shape or an unknown provider family.
